What's new

Every release of Mulembe, newest first. Mulembe updates itself, so you always have the latest.

Mulembe 1.1.0

26 October 2026
  • Plans from $2.99 a month: Personal for you, Team with a seat for each person. Subscribe opens the plans on the website.
  • Next Phase: one click asks Claude for the next phase's prompt and starts it in a new pane next to this one, with the model and effort it names. Phases can also run automatically, one after another, each committing its own work.
  • Phase panes are numbered after the pane they came from (5-1, 5-2), and Close Sub-Panes closes them all at once.
  • Click [Image #N] to see the screenshot you pasted. Pinch, or press Control + and Control −, to zoom.
  • Copying from a pane gives you the full text of a long paste instead of [Pasted text #1].
  • Stop a local server from its 🌐 pill. Servers left running by sessions that ended stop once nothing uses them, like Docker of a project you leave.
  • The 📱 pill shows your project's app in an iOS simulator, and simulators agents leave running shut down by themselves.
  • Parked panes free Claude's memory and pick up the same conversation when you come back. You can also keep working with the lid closed.
  • In Claude's input field, ⌘A and ⌘⇧ with the arrows select your message like in Notes, and ⌘Z brings back deleted text.
  • The folder chooser fits small panes, and the menu bar icon comes back after display changes.
  • Many fixes for reliability, speed and battery life.

Mulembe 1.0.5

18 October 2026
  • Notarized by Apple: Mulembe now opens without a security warning.
  • Keeps Claude Code up to date: when a new version is installed, each Claude that's waiting for you restarts on it in the same conversation. A note on the pane lets you stop it.
  • Update Idle Claudes in the menu bar menu installs the newest Claude Code and restarts the Claudes that are free.
  • Click a file name in a pane to show it in Finder.
  • Press ⌘C with nothing selected to copy the whole message you're typing to Claude.
  • Optional time next to each of Claude's replies (Settings → Claude).
  • Offers to stop a project's Docker when you park its pane or leave it for two hours.
  • Pane header buttons work on the first click, and Mulembe never types into Claude while you have a draft or a question is open.
  • Many fixes for reliability, speed and battery life.

Mulembe 1.0.4

9 October 2026
  • Switch every pane to another account at once (account badge → Switch All Panes To).
  • Safer links: only web and mail links open on a plain click, anything else asks first. Programs can no longer write to your clipboard.
  • Your settings file is never overwritten if it can't be read, and is written safely.
  • Type in All Panes shares only what you type. Switching profiles can't mix panes into the old profile.
  • Less work while idle: fewer screen reads, slower port and Docker scans in the background.
  • The usage limit card fits narrow panes. Shift+Return makes a new line only in Claude and Codex.

Mulembe 1.0.3

6 October 2026
  • A new tutorial with pictures, and a Pane Tour that points at every icon in a pane's header (Help → Pane Tour).
  • Choose which microphone voice input uses, for example your MacBook's while AirPods are connected (Settings → Mouse & Voice).
  • Usage limit card: says which limit was hit and when it resets, with Continue at reset as its own button. Dismiss really cancels it.

Mulembe 1.0.2

5 October 2026
  • Pick a color for each account, and accounts never get the same color, also in Night Shift.
  • Extra Claude accounts show usage and context in their status line too.
  • Parked panes that don't fit show as "+N more", with a list to bring them back.
  • No more false "hit its limit" warning after continuing a conversation on another account.
  • Keep the Screen On Too, now also in the menu bar's Keep Mac Awake menu.
  • Show Mulembe appears in the menu bar only when a window is hidden.

Mulembe 1.0.1

5 October 2026
  • Everything is built in, nothing to install: your agents keep running while Mulembe restarts or updates.
  • Agents keep running even if Mulembe crashes.
  • Fixed a crash when starting voice input.
  • Voice input works with AirPods and other headsets that switch modes while you talk.
