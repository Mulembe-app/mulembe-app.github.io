Installing Mulembe

Last updated: 18 October 2026

Mulembe is signed with an Apple Developer ID and notarized by Apple, so it opens like any other app you download.

  1. Open the downloaded Mulembe.dmg and drag Mulembe into Applications.

  2. Open Mulembe from Applications. The first time, macOS asks if you want to open an app downloaded from the internet: click Open.

  3. That's it: Mulembe opens, and your 14-day free trial starts. From now on it opens normally, and updates install by themselves.

What Mulembe asks for

Only when you use the matching feature: the microphone and speech recognition for voice input, and notifications for "needs you" alerts. Commands you run in a pane can trigger their own requests (for example when a script reads a protected folder). macOS shows those as coming from Mulembe, like it would for Terminal.

Agents that keep running

Mulembe has everything built in, nothing else to install. Your agents run in their own background sessions, so they keep working while Mulembe restarts, updates or even crashes.

macOS may tell you that Mulembe added a background item. That's what keeps your agents running: leave Mulembe switched on in System Settings → General → Login Items & Extensions.
