Installing Mulembe

Last updated: 5 October 2026

Mulembe isn't notarized by Apple yet, so the first time you open it, macOS asks you to confirm. It takes a few seconds, once.

  1. Open the downloaded Mulembe.dmg and drag Mulembe into Applications.
  2. Open Mulembe from Applications. macOS says it can't check it for malicious software: click Done.
  3. Open System Settings → Privacy & Security, scroll down and click Open Anyway next to Mulembe. Confirm with your password or Touch ID.
  4. Mulembe opens. From now on it opens normally, and updates install by themselves.

What Mulembe asks for

Only when you use the matching feature: the microphone and speech recognition for voice input, and notifications for "needs you" alerts. Commands you run in a pane can trigger their own requests (for example when a script reads a protected folder); macOS shows those as coming from Mulembe, like it would for Terminal.

Keeping agents alive through restarts

Mulembe uses tmux to keep your agents running while it restarts or updates. Install it with Homebrew: brew install tmux. Without it, Mulembe resumes your Claude conversations instead.
