Mulembe 1.0.4

  • Switch every pane to another account at once (account badge → Switch All Panes To).
  • Safer links: only web and mail links open on a plain click, anything else asks first. Programs can no longer write to your clipboard.
  • Your settings file is never overwritten if it can't be read, and is written safely.
  • Type in All Panes shares only what you type. Switching profiles can't mix panes into the old profile.
  • Less work while idle: fewer screen reads, slower port and Docker scans in the background.
  • The usage limit card fits narrow panes. Shift+Return makes a new line only in Claude and Codex.
