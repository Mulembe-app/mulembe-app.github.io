Mulembe 1.0.5

  • Notarized by Apple: Mulembe now opens without a security warning.
  • Keeps Claude Code up to date: when a new version is installed, each Claude that's waiting for you restarts on it in the same conversation. A note on the pane lets you stop it.
  • Update Idle Claudes in the menu bar menu installs the newest Claude Code and restarts the Claudes that are free.
  • Click a file name in a pane to show it in Finder.
  • Press ⌘C with nothing selected to copy the whole message you're typing to Claude.
  • Optional time next to each of Claude's replies (Settings → Claude).
  • Offers to stop a project's Docker when you park its pane or leave it for two hours.
  • Pane header buttons work on the first click, and Mulembe never types into Claude while you have a draft or a question is open.
  • Many fixes for reliability, speed and battery life.
